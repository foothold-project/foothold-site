📢 foothold-v1 배포 · 종합보고서 1차 · 평가 영상 갤러리 · 평가 정본 (2026-09-12)

앞으로 정책을 새로 낼 때마다 종합보고서 N차 + gallery-vN 이 한 벌로 쌓입니다. 그 첫 판입니다. 이어서 작업하실 분들은 아래 넷을 보시면 됩니다.

1. 종합보고서 1차 · 기준선 NVIDIA vs A vs foothold-v1 을 같은 조건에서 견줬습니다. 난이도 0.5 성적표 14,400 판이 분모이고, 난이도 곡선까지 합한 전체 원자료는 43,200 판입니다. https://foothold-project.vercel.app/report-v1.html

2. 평가 영상 갤러리 · 84컷. 지형 16종 x 속도 3종의 foothold-v1 48컷과, 격차가 크거나 셋 다 0 % 인 자리의 대조컷 36컷입니다. 지형 · 지형집합 · 속도 · 모델 · 성공률 구간 · 험지 참여도 구간 · 영상 유무로 거릅니다. 조건이 URL 에 남아 링크로 그대로 공유됩니다. https://foothold-project.vercel.app/gallery/

3. 3열 비교 · 같은 지형 · 같은 속도에서 (판, 모델) 세 쌍을 나란히 놓고 한 곳에서 누르면 셋이 같은 시각 기준으로 함께 돕니다. 다음 판이 나오면 열 하나만 바꾸면 됩니다. https://foothold-project.vercel.app/gallery/compare/

4. 평가 프로토콜 정본 · 무엇을 어떤 기준으로 재고, 같은 결과를 어떻게 재현하며, 대표 영상을 어떻게 뽑는지. 수치를 인용하기 전에 여기를 보십시오. https://foothold-project.vercel.app/research-20260911-eval-protocol-v2.html

성적 (난이도 0.5 · 1.0 m/s · 기준선 -> foothold-v1) gap 1 % -> 100 % · pit 2 % -> 100 % · floating_ring 0 % -> 99 % · rails 8 % -> 48 %. stepping_stones 는 세 모델 다 0 % 로 2차의 첫 과제입니다. 기존 험지 6종은 18칸 전부 기준선 이상입니다.

영상 보는 법. HUD 에 명령 속도 · 실제 속도 · 전진 거리 · 자세가 얹혀 있습니다. 재생기의 배속 단추로 0.25 ~ 2배를 고를 수 있고, 파일은 한 벌입니다. 다만 HUD 의 추종 표시는 전후 오차의 누적 평균이고 평가의 속도추종 판정은 전후와 좌우를 합친 평면 오차입니다. HUD 로 판정을 역산하지 마십시오.

직접 뽑으려면 저장소를 받고 pip install av 한 번 뒤 python sim/eval/render_gallery.py --checkpoint models/foothold-v1.pt 입니다. 옵션 없이 한 줄이면 같은 한 벌이 나옵니다. 자세한 것은 정본 9절과 10절에 있습니다.

읽을 때 주의할 것 둘. 옆에 적힌 성공률은 그 자리 평가 100판의 집계이고, 영상은 따로 촬영한 시연 한 판입니다. 평가 칸 144개 가운데 60개는 성적만 있고 영상이 없는데, 갤러리는 그것을 「영상 없음」으로 보여 주며 「미평가」와 구별합니다. 대조컷을 다 채우는 것은 별도 작업으로 잡아 두었습니다.

발행 전에 codex 검증을 여섯 번 돌려 33건을 고쳤습니다. 마지막 회차가 원자료 43,200행 · 성적표 144칸 · 영상 84개 27,494프레임을 독립 재측정해 전부 일치를 확인했습니다.
