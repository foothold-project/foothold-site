1. 다섯 축과 채용 시장의 직무명

프로젝트 축채용 시장 직무명우리 산출물 = 포트폴리오 증거

공유 대화의 프레임(RL 학습 / Terrain·DR / Sim-to-Real / SLAM / Nav2·통합 + 백업 페어)이 우리 두 트랙 구조와 정확히 포개진다. 역할 논의는 이 틀 위에서 "각자 메인 + 겹침 1개"로 정하면 된다.

2. 팀원별: 가진 것 → 이 프로젝트의 대응물 → 포트폴리오 문장

팀원가진 것이 프로젝트에서포트폴리오 문장 (전·후)
오흥재영상·VFX 12년, 카메라·공간·3D 파이프라인PM + 실공간 3D 재구성·실사급 렌더 축"3D를 다룬다" → "물리 시뮬레이터와 현실을 잇는 디지털 트윈을 설계·검증했다"
임석헌비전 학습·파인튜닝 R&D, 데이터 구축RL 정책 주담당. 보상·관측·커리큘럼 설계 (occlusion 관심 = 부분관측 문제와 직결)"지도학습을 했다" → "강화학습으로 축을 확장하고, 실물 센서 제약에서 역산해 관측을 설계했다"
맹라현Blender·3ds Max·Unity·프리미어·웹지형·씬·시각화 주담당. 팀에서 3D 툴을 실제로 다루는 유일한 사람: 없으면 팀이 막히는 자리"3D 툴을 쓸 줄 안다" → "물리 시뮬레이터용 에셋 파이프라인을 구축하고 실험 결과를 시각화했다"
오현민CV 분류, 프론트엔드인지·데이터·평가 주담당. 정제된 데이터셋이 없는 세계: 촬영·재구성·검증 전 과정이 우리 책임"공개 데이터셋으로 학습했다" → "현실 공간을 재구성해 학습 환경으로 만들고 정책을 평가했다"
이민우웹 풀스택, 서버 구성·운영. 사족보행 1픽RL 정책 부담당(관심 반영) + 학습 환경·인프라. 인프라는 잡일이 아니라 크리티컬 패스: 5인이 동시에 못 돌리면 팀 전체가 멈춘다"웹을 만든다" → "강화학습 실험이 도는 인프라를 세우고, 정책 학습에 참여했다"

3. 이 지도를 쓰는 법

  1. 역할 확정 회의에서 각자 "메인 축 1 + 겹침 1"을 이 표에서 고른다. 겹침은 백업 페어가 된다.
  2. 전담 멘토의 개별 취업 멘토링(이력서·포트폴리오·기업 매칭)과 접속: 축이 정해지면 포트폴리오 문장이 정해지고, 멘토가 그 문장을 검증해 준다.
  3. 각 축의 "증거"는 이미 웹에 쌓이고 있다: 연구 기록·평가 CSV·영상. 12월의 포트폴리오는 새로 만드는 게 아니라 여기서 골라 담는 것이다.
