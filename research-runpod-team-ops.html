1. 팀 계정과 권한 4종 확인됨

우리 팀 워크스페이스는 별도 지갑이 아니라 팀장 계정을 팀으로 전환한 것이며, 크레딧 잔액은 계정(=팀)당 하나를 전원이 공유한다. 크레딧은 선불이며 환불·인출 불가.

팀원 초대·권한 변경·계정 설정XXXO

현황과 권고: 현재 5인 전원 Admin이다. Admin은 팀원 강퇴·계정 설정·결제수단까지 전부 가능해, 실수 하나 또는 계정 1개 탈취로 팀 전체가 노출된다. 권고 재배분: Admin 2 (팀장 + 백업 1) / Dev 3 (Dev로도 팟 운용에 부족함이 없다). 기본 지출 한도 $80/hr는 하향 조정 권고, 저잔액 알림 켜기 (아래 §3 볼륨 소실 예방).

2. 결제: "각자 카드로 각자 몫 충전"이 되는가

  • 공식 문서의 답: 명시 없음 미확인. 카드 여러 장 등록 가능성은 시사되지만("예비 결제수단을 등록해 두라" 권고 존재), 1회 충전 시 카드를 선택하는 절차는 어느 문서에도 없다.
  • 따라서 월요일 상신 전에 실측 3점이 필요하다: ① Billing에 두 번째 카드가 등록되는가 ② 충전 모달에 카드 선택이 있는가 ③ 발행 영수증에 카드 식별 정보(뒷 4자리)가 남아 개인 비용 증빙이 성립하는가. 결제는 Stripe 경유라 영수증에 카드 정보가 남을 가능성이 높지만 이는 추론이다 추측.
  • 주의: 짧은 시간에 여러 카드 결제가 몰리면 이상거래로 차단될 수 있다는 공식 안내가 있다. 5명이 동시에 충전하지 말고 시차를 둘 것. 선불카드는 거래당 최소 $100 제약.
  • Auto-pay는 기본 저장 카드에서 자동 충전된다. 팀 운용에서는 OFF 유지 (합의 8/21).

3. 네트워크 볼륨 표준 운용 확인됨

  1. 생성: Storage → New Network Volume → 데이터센터 선택 → 크기(GB). Secure Cloud 전용이며, 볼륨은 만든 데이터센터에 영구 고정된다: 팟도 그 데이터센터에서만 띄워야 한다. 데이터센터는 GPU(4090) 재고와 S3 API 지원 여부를 보고 정한다.
  2. 연결: 팟 배포 시점에만 붙일 수 있다. 떠 있는 팟에 나중에 붙이거나 뗄 수 없다 (팟을 지워야 변경). 마운트 경로 /workspace.
  3. 요금: $0.07/GB/월 (1TB 초과분 $0.05). 100GB = 월 $7. 팟 유지 대비 압도적으로 싸다.
  4. 크기: 확대만 가능, 축소 불가 → 작게 시작 (20~50GB 권장, 필요 시 확대).
  5. 소실 경고: 잔액이 $0이 되면 팟은 정지되지만 볼륨 요금은 계속 쌓이며, 잔액 방치 시 볼륨이 결국 terminate될 수 있다. 저잔액 알림 필수.
  6. 동시 쓰기 주의: 여러 팟이 같은 볼륨에 동시에 쓰면 손상될 수 있다. 같은 시간대에 같은 볼륨으로 작업할 때는 폴더를 나눈다.
  7. 이미지 캐싱: Runpod은 컨테이너 이미지를 캐시한다 (단위·보장은 문서에 없음 미확인). Isaac Sim «설치»는 반복되지 않고 이미지 pull이며, 캐시에 있으면 빠르게 뜬다. 무거운 것(에셋·체크포인트)은 볼륨에, 이미지는 표준 템플릿 그대로.
  8. S3 호환 API: GPU 없이도 볼륨에 파일을 넣고 뺄 수 있다 (Settings → S3 API Keys, 지원 데이터센터 한정). 팟을 켜기 전 데이터 선적재에 유용: 팟 과금 시간에서 업로드 시간을 빼내는 수단이다.

4. UGREEN NAS 연계 아키텍처 (설계, 팀장 실측 예정)

원칙: 핫 데이터는 데이터센터 안(네트워크 볼륨), 콜드 아카이브는 NAS. 가정 회선 지연·대역폭 때문에 NAS를 팟의 작업 디스크로 직결하는 것은 성립하지 않는다.

층위치무엇을왜
작업팟 컨테이너 디스크실행 중 임시 파일가장 빠름, 종료 시 소멸
영속네트워크 볼륨 (/workspace)코드·체크포인트·실행 결과팟 종료에도 생존, $0.07/GB/월
아카이브UGREEN NAS (팀 폴더)완료된 실험 결과·영상·리포트 원본팀 공유·무료·웹 게시 원천
  • 이동 경로: 작업 종료 시 팟에서 rclone/rsync로 볼륨 → NAS 하향 동기화. 팟에 Tailscale을 설치하면 NAS 직통 터널이 생긴다 (팀장 셋업 예정). 대안: 볼륨의 S3 API를 NAS 쪽에서 당기기.
  • 효과: 볼륨은 작게 유지되고, NAS 팀 폴더가 "클라우드처럼 쓰는" 팀 저장소(합의 8/21)와 한 몸이 된다.
