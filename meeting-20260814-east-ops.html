정본은 오흥재가 2026-08-14에 전사로 작성했다. 맹라현이 2026-08-25에 같은 자리의 브리프를 제출했고, 2026-08-26에 그중 정본에 없던 것을 표시해 합쳤다. 「맹라현 추가」로 적힌 절이 그것이다. 자료: 녹음 19분 7초 → MOSS 화자분리 전사 258세그먼트. 전 인용에 타임코드. 참석: 이스트소프트 이사 · 전승묵 운영진 · 김민수 담임 · 팀 전원. 화자 매핑: S01 = 오흥재 팀장 · S02 = 이스트 이사 · S03 = 운영진·담임 측(조선대 연락 담당) · S04 = 팀원 · S05 = 단발 1명. 확정값은 운영 재확인이 남아 있다. 어제 자리: 8/13 조선대 미팅.

한 줄 요약

원안 확정이다. 이사: "이거는 했으면 하기로 결론은 난 거예요. 이왕이면 성공을 해야" [06:26~06:32]. 김유진 멘토 때 추린 방향 그대로 가고 미세 조정만 한다 [18:12~18:22].

그리고 미팅 도중에 어제의 최대 쟁점이 뒤집혔다.

F0 대반전: 저수준 제어는 「가능」이었다

미팅 중 조선대에서 연락이 왔다.

"방금까지 안 된다고 했는데 전화가 와서는 된다고" [03:41] "된다고, 가입까지 보내주셨어요" [05:22]

경위: 교수님이 저수준을 직접 다뤄본 적이 없어 그렇게 말했던 것이고, 공식 문서를 찾아보고 「가능」으로 정정했다 [13:28~13:58].

단서도 함께 왔다. "가능은 한데 이쪽 부분은 만만치 않다" [14:09].

남은 것은 실기 실측뿐이다. 그날 오후 실측으로 마무리하기로 했다 [15:42] [17:54~17:58].

이 정정으로 8/13의 F0(「조선대 Go2 EDU에서 저수준 전환이 되는가」)은 문서상 「가능」으로 기울었다. 다만 그것도 전언이고, 최종 판정은 현장 실측이다. 전날 문서의 미확인 표기는 그 뜻이다.

그날 무슨 일이었나 (맹라현 추가)

아래는 정리 맹라현 (2026-08-25 제출) 브리프다. 근거는 본인 회의 노트다. 두 기록은 초점이 다르므로 함께 본다. 장소는 이스트, 어제 조선대 OT·조율의 후속 자리다.

어제 조선대에서 기획과 제시안이 갈린 다음 날, 이스트 창구와 멘토 라인을 한 테이블에 올려 역할을 나눴다. 질문은 「지원을 어디서 받고, 멘토는 누구 라인인가」였다.

이스트가 맡는 축은 ROS2 교육과 인프라로 고정했다. Win 물리서버, GPU 두 장(RTX 2000), 컨테이너 GPU 사용 가능 여부는 아직 확인 전이다. 자율주행·SLAM을 이스트 교육 트랙에 넣지 않는다. 그건 별도 인력 트랙이다.

멘토 전담은 이스트 인프라 라인에만 기대지 않는다. 인사이트(김유진) 계열로 보강하고, 구이사 가이드를 체크한 뒤 담당 강사 배치를 요청한다. 교육은 팀이 진행하되 난이도를 조율하고, 전담강사 코드 리뷰를 넣는다. 전담강사 없이 팀만으로 코드 리뷰를 닫지 않는다.

범위 조정안은 유지한다. 일정을 맞추려고 범위를 줄이지 않는다. 일정만 늘리고 목표를 방치하지도 않는다. 프로세스는 목표 설정(제안서·범위 유지) → 스케줄링(ROS2 1~2개월 → 실기 3~4개월, 시뮬 포함) → 구체 로드맵(10~12월 테스트 · 영상 시연)이다.

10월 축은 ROS2 학습 다음에 로봇 구현과 영상 시연이다. 산출물도 그 영상 시연으로 잡았다.

하드웨어·SDK, 아직 물어봐야 하는 것. 교육용 SDK가 하드웨어에 붙어 있는지, 발표 때 로봇을 반출할 수 있는지는 유진님께 다시 묻는다. SDK를 확인하기 전에 발표 반출을 가정하지 않는다. Cmd 코드 스위치 on/off도 같이 본다.

GPU를 확인하기 전에 시뮬 일정을 확정하지 않는다. 이스트 컨테이너 GPU와 Win 물리서버 RTX 2000 두 장을 금주에 확인한다. 조선대 트랙과 역할은 어제 OT 후속으로 다시 정렬한다.

#그날 고정한 것
1이스트 지원 축 = ROS2 교육 · 인프라 (Win 물리서버)
2멘토 전담 = 인사이트(김유진) 계열. 구이사 가이드 체크 후 강사 배정
3범위 조정안 유지. 일정만 목표 → 스케줄 → 로드맵으로 푼다
410월 축: ROS2 학습 → 로봇 구현 · 영상 시연
5자율주행·SLAM은 별도 인력 트랙. 이스트 교육에 넣지 않는다
6교육 = 팀 진행 + 난이도 조율 + 전담강사 코드 리뷰

지키면 되는 것, 늦으면. 범위는 유지한다. 이스트는 ROS2와 인프라, 멘토는 인사이트, 10월은 영상 시연이다. 늦어도 SLAM을 이스트에 넣지 않는다. GPU·SDK가 늦어도 제안서 방향은 유지한다. 교육 난이도를 확인 없이 고정하지 않는다.

사슬은 이렇다. 제안서 확인 → 내부 정렬 → 목표 · 스케줄 · 로드맵 → 강사 · GPU · SDK.

회의 PDF 노트의 일정 골격

  • ROS2 1~2개월 → 실기 3~4개월(시뮬 포함) → 10~12월 테스트
  • 10월 목표: ROS2 학습 후 로봇 구현. 영상 시연
  • 하드웨어 액션: 교육용 SDK 부착 여부를 유진님께 재확인 · 발표 반출 가능(B안 개체로 추정)

풀어 적으면 이렇다. 당일은 제안서 방향·범위를 확인한 뒤 이어서 논의한다. 금주는 내부 정렬이 필요한 항목을 재논의하고, 인사이트 담당 강사 배치를 요청하고, 컨테이너 GPU와 Win/RTX 2000×2를 확인한다. 차주는 목표 → 스케줄 → 로드맵 초안을 잡고, SDK 하드웨어 부착 여부와 발표 반출을 유진님께 재확인한다.

팀장 소견

  • 우리 기획(각자 탐구 영역 + 전체 그림)의 방향은 좋다. 관건은 「무엇을 해결할 것이고 어떤 이야기로 풀 것인가」이다.
  • 조선대 커리큘럼은 개인적으로 매우 원하던 학습 내용이다. 단 팀 프로젝트 관점은 별개다. 미답 논의점들을 다시 grilling 해서 진행할 것.
  • 개인 일정: 차주 월요일까지 서울. WS는 원격 제어로 운영한다. 워크스테이션 이야기다.
