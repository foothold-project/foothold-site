이슈 #76. 서브 에이전트가 56개 문서를 열어 메타 5줄·절 제목·결론·상호 링크를 추출해 판정했고, 팀장 세션이 인용문 20건을 원문과 전수 대조해 검증했다 (20/20 실재 확인).

1. 왜 이 표를 만드나

지금 사이트에는 묶음(허브)만 있고 관계가 없다. 그래서 표지에 7개 절이 평평하게 놓이고, 그중 「길잡이」·「찾아보려면」은 다른 절의 문서를 다시 가리키는 절이라 같은 문서가 두 번 나온다.

층위가 서면 노출 기준이 저절로 나온다. 뿌리는 표지에, 하위는 상위 안에서.

2. 목적별 분포

목적개수뜻
본PoC3우리가 돌려 숫자를 얻은 것
PoC시험2되는지 보려고 돌려본 것
파이프라인점검3환경·하네스가 맞는지
자료조사14밖에서 찾아 정리
운영34규칙·결정·회의·일정

본선 실측이 3편뿐이다. 우리가 직접 돌려 숫자를 얻은 문서는 8/9~8/22 사이의 셋이고, 8/27 이후 문서는 전부 계획과 규칙이다. 이것이 지금 프로젝트의 실제 무게중심이다.
