왜 이 문서가 따로 있나

같은 사실을 세 군데에 손으로 적어 두었다가 한 군데만 고쳤기 때문이다.

2026-08-27 에 작업 영역을 5갈래에서 8갈래로 바꿨다. GitHub 라벨은 바꿨고 COLLAB.md 표도 바꿨다. 그런데 팀 소개 덱과 피치 덱은 그대로였다. 발표에 쓰는 두 장짜리가 8/13 의 옛 5분야(PM·Digital Twin Policy·RL Scene·Visualization Environment·Infra Perception·Data)를 여전히 보여주고 있었다.

원인은 부주의가 아니라 구조다. 손으로 관리하는 마스터가 셋이면 셋 다 고쳐야 하고, 셋 다 고쳤는지 확인해 주는 것이 아무것도 없다. 커널 철칙 4 와 같은 부류다.

그래서 이 문서를 정본 하나로 두고, 나머지는 여기서 생성한다.

1. 작업 영역 8갈래

두 트랙(A 시뮬 · B 실기)과 공통(C)으로 갈린다. 트랙의 뜻은 FLOW 참조.

갈래무엇을 하나주담당부담당폴더

주담당은 「혼자 한다」가 아니라 「막히면 이 사람에게 묻는다」이다. 부담당은 리뷰와 대체를 맡는다. 한 사람이 자리를 비워도 갈래가 멈추지 않게 두 명 이상을 둔다.

옛 5갈래는 왜 버렸나

8/13 에 정한 옛 5갈래는 평가 체계 · 험지 환경 · 정책 학습 · 실기 전이 · 운영이었다. 이것은 8/19 두 트랙 전환 이전의 것이다. 실기 전이 는 그날 목표에서 뺀 이름이고, 트랙 B(항법)가 통째로 빠져 있었다. 그래서 8/27 에 폐기했다 (DECISIONS 08-27).

2. 사람별 배치와 강점

발표 카드는 아래 항목을 그대로 읽어 만든다. 항목 이름을 바꾸면 빌드가 깨진다.

오흥재

  • 갈래: B/항법 · C/운영
  • 대표: 예
  • 한 줄: 프로젝트 리딩 · 항법과 운영
  • 메인 역할: 일정·범위 관리, 멘토 인터페이스, 트랙 B 항법 축과 팀 인프라
  • 보유 강점: 영상·VFX 12년· 카메라·공간·3D 파이프라인 설계, 포인트클라우드 기반 공간 재구성 실무, 기획·구조 설계
  • 협업 스타일: 결정의 배경까지 문서로 남겨, 누구든 중간에 이어받을 수 있게 한다
  • 피치 한 줄: 리딩 · 항법 · 운영. 영상·VFX 12년, 카메라·공간·3D 파이프라인, 포인트클라우드 재구성 실무.

임석헌

  • 갈래: A/정책학습
  • 한 줄: 강화학습 정책 · 모델
  • 메인 역할: 보행 정책 학습, 보상 설계, 실험 설계와 반복
  • 보유 강점: 비전 모델 학습·데이터 구축, 파인튜닝 R&D, LLM 판단 로직 설계
  • 협업 스타일: 직접 돌려본 결과를 근거로 가져와 논의를 빠르게 좁힌다
  • 피치 한 줄: 보행 정책 학습 · 보상 설계 · 실험 반복. 비전 모델 학습·데이터 구축, 파인튜닝 R&D.

맹라현

  • 갈래: A/지형씬제작 · A/트윈렌더
  • 한 줄: 3D 지형 · 트윈 · 렌더
  • 메인 역할: 시뮬 지형 제작, 실공간 복원과 렌더 시연
  • 보유 강점: Blender · 3ds Max · Unity, 2D CAD, 프리미어, HTML/CSS, MongoDB · SQL, Git · 제작부터 데이터까지
  • 협업 스타일: 복잡한 구조를 눈으로 볼 수 있게 만들어, 말로 하면 길어질 논의를 짧게 만든다
  • 피치 한 줄: 시뮬 지형 제작 · 실공간 복원 · 렌더 시연. Blender · 3ds Max · Unity, 웹·DB까지.

오현민

  • 갈래: A/평가 · B/인지
  • 한 줄: 일반화 평가 · 인지
  • 메인 역할: 미경험 지형 일반화 벤치마크와 지표, 실기 LiDAR·카메라 인지
  • 보유 강점: 컴퓨터비전 분류, 프론트엔드 구현, AI 부트캠프 수료
  • 협업 스타일: 결과를 수치로 확인한 뒤 넘겨, 뒷단이 다시 검증할 일을 줄인다
  • 피치 한 줄: 일반화 벤치마크·지표 · 실기 센서 인지. 컴퓨터비전 분류, 결과 화면 구현.

이민우

  • 갈래: C/기록
  • 한 줄: 기록 · 문서 · 대외보고
  • 메인 역할: 회의록과 문서 정본화, 백과·커리큘럼, 발표 자료와 대외보고
  • 보유 강점: 웹 풀스택· 기획부터 배포까지 직접 구현, 서버 구성·운영
  • 협업 스타일: 막힌 곳을 먼저 찾아 손대고, 남이 그대로 쓸 수 있게 정리해 넘긴다
  • 피치 한 줄: 회의록·문서 정본화 · 백과·커리큘럼 · 대외보고. 웹 풀스택, 서버 구성·운영.
