시뮬레이션 강화학습

Isaac Lab에서 Go2 험지 보행 정책을 학습한다. 실기 배포는 하지 않고, 학습 곡선·정책 재생 영상·지형 난이도별 정량 평가가 중간발표의 산출물이다.

1시뮬레이터 선택 · Isaac Lab 주력, 분기 규칙 포함

2026년 8월 기준 Go2 험지 RL의 사실상 표준은 NVIDIA Isaac Lab(2.1~2.3 + Isaac Sim 4.5/5.1)이다. Isaac-Velocity-Rough-Unitree-Go2-v0 태스크가 지형 커리큘럼·도메인 랜덤화·PPO(rsl_rl) 설정까지 포함해 기본 제공되므로, 7주 안에 "셋업"이 아니라 "실험"에 시간을 쓸 수 있는 유일한 선택이다.

컴퓨트 환경 · RunPod 확정

RunPod에서 Isaac Lab이 headless로 구동되는 것을 확인, 강화학습 컴퓨트는 RunPod으로 확정. 셋업이 심하게 막히면 MuJoCo Playground(CUDA만 필요)가 백업 경로.

주의

로컬 노트북(RTX 3060 6GB)은 Isaac 최소사양 미달 · 코드 편집·결과 확인용으로만 쓰고 학습은 RunPod 전용. VRAM이 작은 GPU를 고르면 험지 4096 env가 안 돌아가니 Pod 생성 시 VRAM 8GB+ 확인.

2험지 RL 표준 레시피

  • 알고리즘: PPO (rsl_rl 구현). 병렬 환경 ~4096개, 평지 20~30분·험지 수 시간(A10G/L4 기준).
  • 관측 (proprioceptive, ~48차원): base 각속도 · 중력벡터 투영 · 속도 명령(3) + 관절 위치/속도(12+12) + 이전 액션(12). 험지 인지형은 로봇 주변 격자 고도 height scan(~187차원) 추가.
  • 액션: 관절 목표각 12차원 → PD 제어(kp 25~40, kd ~0.5). 정책 50Hz, 물리 200Hz+.
  • 보상: 속도 명령 추종(+) / z속도·roll·pitch 페널티 / 토크·액션 변화율 페널티 / 발 공중시간 보너스 / 넘어지면 종료. legged_gym 보상 코드가 표준 레퍼런스.
  • 지형 커리큘럼: 평지 → 경사 → 계단·요철. 성공하면 승급, 실패하면 강등 (Isaac Lab terrain generator 내장).
  • 도메인 랜덤화: 마찰, 질량/무게중심, 모터 강성, 관측 노이즈, 외력 푸시.

3핵심 논문 5편

  • Learning to Walk in Minutes (Rudin+, CoRL 2021) · GPU 병렬 수천 env + PPO로 분 단위 학습. legged_gym의 원 논문. arXiv
  • Learning Quadrupedal Locomotion over Challenging Terrain (Lee+, Sci. Robotics 2020) · 지형 커리큘럼 + teacher-student, blind 험지 보행의 기틀.
  • Learning Robust Perceptive Locomotion (Miki+, Sci. Robotics 2022) · 고도맵 + proprio 융합, ANYmal 험지 SOTA.
  • Walk These Ways (Margolis & Agrawal, CoRL 2022) · 보행 스타일을 명령으로 조건화. GitHub
  • Extreme Parkour (Cheng+, 2023) · 비전 기반 파쿠르. 심화 참고용 (우리 범위 밖).
