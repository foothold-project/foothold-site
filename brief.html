03왜 이 프로젝트인가

“로봇이 잘 걷는다”만으로는 설득이 안 됩니다. 상용 제품을 사면 이미 걷기 때문입니다. 아래가 우리가 세울 수 있는 이야기입니다.

훅 로봇개가 계단을 오릅니다. 이건 이미 됩니다. 사서 쓰면 돼요.
반전 그런데 모래에 발이 빠지는 순간 무너집니다.
왜 로봇은 지면이 얼마나 미끄러운지, 얼마나 꺼지는지 잴 수가 없습니다. 마찰계수 센서도 강성 센서도 없습니다. ← 커리큘럼 A12 「관측 설계」
시도 그럼 시뮬레이터에서 모래를 만들어 학습시키면 되지 않냐고요?
실패 Isaac Lab은 모래를 시뮬레이션하지 못합니다. 강체와 지형 높이만 다룹니다. 공식 API 문서·NVIDIA 포럼에서 직접 확인
진짜 원인 물성을 알 수도 없고, 시뮬로 만들 수도 없습니다.
발상 전환 그러면 알려고 하지 맙시다. 모르는 채로 적응하게 합니다.
우리가 할 것 넓은 물성 분포로 학습 → 실제 모래와 자갈에서 평가.

  • Boston Dynamics 개발자 문서 — “graph nav map must be uploaded”, “go here, do this pattern”
  • ANYbotics 온보딩 문서 — “Operators can guide the robot through facilities… after which the robot will autonomously repeat”

04🔴 쓰면 안 되는 주장

아래는 조사에서 반증되었거나 근거가 부족한 것들입니다. 발표·보고서·멘토 면담에서 쓰면 그 자리에서 무너집니다.

✕ 쓰지 말 것 · ✓ 정확한 표현
✕ “바퀴형은 계단·잔해를 못 간다” ✓ Go2-W(35°/70cm)가 반증. “관절 없는 고정 바퀴만” 못 오름
✕ “Go2가 Go2-W보다 험지에 낫다” ✓ 공식 스펙상 거짓 (30°/15cm vs 35°/70cm)
✕ “우리 로봇이 하수관에 들어간다” ✓ 물리적 불가. Go2 폭 31cm vs 전용 크롤러 7.6cm급. 대형 관로·맨홀 하부·지하공동구로 한정
✕ “우리 로봇이 정유공장에 들어간다” ✓ 방폭(ATEX) 인증이 ANYmal X에만 있음. Go2는 인증 자료 없음
✕ “밀폐공간 사망의 60%는 구조자” ✓ 출처마다 25~63%로 상충. “절반 수준(KOSHA)”까지만
✕ “로봇이 사망사고를 X% 줄인다” ✓ 인과 근거 공개된 것 없음. “줄일 수 있는 구조가 있다”까지만
✕ “GPU 2장으로 학습을 2배 빠르게” ✓ peer access 미지원. “동시 2인 실험”이 정확한 표현
✕ “바퀴가 다리보다 83% 효율적” ✓ 회사 마케팅 수치. 같은 연구실 동료심사 논문은 53%
✕ “사족보행 시장 $37억” (단일 인용) ✓ 기관별 2~5배 차이. Unitree 누적 출하 3만 대가 검증 가능
✕ “우리 씬이 더 사실적이라 성능이 좋다” ✓ 반박 논문 존재. 주역은 RL과 공간 랜덤화

왜 이 목록이 있나 — 이 프로젝트를 준비하면서 위 주장들을 실제로 한 번씩 썼다가 근거를 찾는 과정에서 전부 무너뜨렸습니다. 같은 함정에 다시 빠지지 않기 위한 목록입니다.
